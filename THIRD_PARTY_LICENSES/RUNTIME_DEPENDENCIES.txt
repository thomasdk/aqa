AQA Embedded Python Packages
======================================

These packages are installed from requirements-runtime.txt into every embedded
Python runtime. The exact installed copies retain available upstream license
and NOTICE files under lib/python3.13/site-packages/*-dist-info/licenses/.
Loguru 0.7.3 is the verified exception on macOS: its wheel omits a license file,
so `LOGURU-0.7.3-MIT.txt` supplies the exact upstream notice. Windows-only
packages are marked below. Build and test dependencies are not installed into
the packaged runtime.
